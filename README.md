<h2>課題2 指標説明</h2>
<li>League: リーグ。セはセントラルリーグ、パはパシフィックリーグ</li>
<li>Win:　勝利数。その年に投手についた勝ちの数。</li>
<li>Lose: 敗戦数。その年に投手についた負けの数。</li>
<li>AVG: 打率。安打数÷打席数。</li>
<li>Game: 試合数。</li>
<li>turn_at_bat: 打席数。
<li>AB: 打数。打席数から四死球、犠打、犠飛、打撃妨害、藻類妨害による出塁の数を除いたもの。
<li>R: 得点数。
<li>Hit: 単打数。単打、二塁打、三塁打、本塁打の総数。
<li>2B :ツーベース、二塁打の数
<li>3B: スリーベース、三塁打の数
<li>HR: ホームラン、本塁打の数
<li>BH:　塁打。単打数+2*二塁打数+3三塁打数+4*本塁打数
<li>RBI: 打点
<li>SB: 盗塁数
<li>CS: 盗塁失敗数
<li>SH: 犠打
<li>SF: 犠飛
<li>BB: 四球
<li>IW: 故意四球
<li>HBP: 死球
<li>SO: 三振数
<li>DP: ダブルプレー。併殺数。
<li>SLG: 長打率。塁打÷打数。
<li>OBP: 出塁率。(塁打+四死球数)÷打席数
<li>OPS: 長打率+出塁率
<li>ERA: 防御率。自責点*9÷投球回
<li>S: セーブ数
<li>H: ホールド数
<li>HP: ホールドポイント数。ホールド数+リリーフについた勝ち星の数
<li>CP: Complete Pitch。完投数
<li>BF: 対戦打者数 
<li>IP: 投球回
<li>H_P: 被安打数
<li>HR_P: 被本塁打数
<li>BB_P: 与四球
<li>IW_P: 与故意四球
<li>HBP_P: 与死球
<li>K: 奪三振数
<li>WP: ワイルドピッチ。暴投。
<li>Balk: ボーク
<li>R_P: 失点
<li>ER: 自責点
